The ls -lsa command lists directory contents with four combined settings:
 ls: The base list command.
 -l: Long format (shows details like permissions, owner, bytes, and date).
 -s: Size (adds the allocated block size column on the far left).
 -a: All files (includes hidden files starting with a .).

what I learned :
As a beginner, I learned that Linux logs act like digital security cameras. 
I learned about how logs are created, especially in linux, how rsyslog process log messages, standards for managing Logs, how to write rule to

SOC perspective :
From a SOC perspective, these logs provide the vital clues needed to monitor networks. Mastering rsyslog to isolate events, like SSH logins, allows 
analysts to detect brute-force attacks, track unauthorized access, and rapidly accelerate incident investigations.
